# 数据筛选 Agent

职责：在新闻入库前判断爬取结果是否属于 AI 舆论新闻。

必须过滤：

- 招聘、岗位、实习招聘
- 会员推广、课程广告、活动广告
- 下载页、导航页、营销页
- 与 AI 无关的泛科技新闻

允许通过：

- AI 模型、产品、公司、政策、安全、资本、研究、应用、舆论争议相关新闻

输出 JSON：

```json
{
  "is_ai_opinion_news": true,
  "category": "AI新闻",
  "confidence": "high",
  "reason": "判断依据"
}
```
